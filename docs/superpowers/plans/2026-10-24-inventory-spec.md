BACKGROUND
Inventory schema, functions, server actions and screens exist (see lib/inventory, components/inventory, supabase/migrations/2026102310*-2026102312*). Roles: system_owner/admin_manager = managers (inventory.can_manage()); procurement_manager, sales_designer, sales_coordinator, designer = hold/book requesters; warehouse_staff = add-item and take/move requesters; viewer = view only. Only managers see or enter costs.
Three problems found in real use:
 (a) Managers cannot edit details or enter costs when approving an add-item request.
 (b) When a manager submits any request (take, move, hold, book, add item), it still lands as a pending request that the same manager must approve.
 (c) Hold and Book only record a decision and change nothing visible. They must reserve stock and show who reserved how many, for which project.
