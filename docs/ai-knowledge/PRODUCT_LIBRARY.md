# Product Library, Smart Setup, brands and materials

## Add and manage products ? implemented entry points

`/products` renders the template page; `?priceStatus=due` redirects to price updates. `/products/templates` is another entry, and `/products/management` redirects to `/products/manage`: [root](../../app/products/page.tsx), [templates](../../app/products/templates/page.tsx), [redirect](../../app/products/management/page.tsx), [manage](../../app/products/manage/page.tsx). The template page requires the product library manager guard. Add/edit uses [ProductTemplateForm](../../components/products/product-template-form.tsx), calling create/update in [actions](../../app/products/templates/actions.ts); the same actions include a quotation-modal creation path.

The [draft contract](../../lib/products/product-template-draft.ts), [commercial validation](../../lib/products/product-template-commercial-validation.ts), [pricing groups](../../lib/products/base-model-pricing-groups.ts), [version helper](../../lib/products/pricing-write-version.ts), and [price check](../../lib/product-price-check.ts) are starting points. The page reads `brands`, `product_categories`, `product_templates`, `product_components`, material links, price history and quotation items. See [database guide](../DATABASE.md) and migrations for exact schema and RLS. Changes can affect quotation selection, saved snapshots, pricing and documents. Tests: [draft](../../lib/products/product-template-draft.test.mts), [validation](../../lib/products/product-template-commercial-validation.test.mts), [pricing version](../../lib/products/pricing-write-version.test.mts), [snapshot](../../lib/quotations/product-template-snapshot.test.mts).
