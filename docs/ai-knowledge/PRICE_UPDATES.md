Full import format coverage, all current tables and live deployment state: **NOT VERIFIED**.

Several confirmed single-target alias tiers may reach one merged pricing row. The matcher retains `aliasSources`: equal prices/currencies compare normally, while conflicting prices/currencies make every alias ambiguous. Smart Setup coalesces only equal alias groups; single-price Apply rechecks fresh aliases and source identities before writing. Price-line suggestions allow an additional tier when the row names it and every already linked tier, or (picker only) when its price and currency equal the row's price; unrelated tiers are identified against all source tiers, including linked ones. A tier with no name/note/id clue is suggested by equal price (reason "price") only when no row of the code names any tier and exactly one row has that price and currency. No binding schema or RPC change is involved.

Announced price change notices: [rules](../../lib/products/price-announcements.ts), [panel](../../components/products/price-announcement-panel.tsx), [migration](../../supabase/migrations/20261106100000_brand_price_announcements.sql). A notice never changes a library price. A quotation item that ticks it carries the uplift in `unit_price` and records it in `source_component_data.announced_price_change`; `original_source_totals` keeps the library price.
